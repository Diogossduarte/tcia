Modelos de anamnese

Descreva a estrutura do prontuário em texto livre: cada seção com ## Título:, uma descrição do que deve conter e regras entre parênteses (ex.: "incluir apenas se mencionado; caso contrário, omitir"). Inclua uma linha Formato: se quiser (ex.: "Formato: texto corrido"). É esse gabarito que a IA preenche com o que foi captado.

Configuração do organizador (API Groq)

O processamento do prontuário usa a API da Groq (gratuita). Cole sua chave (gsk_...) — ela fica salva apenas neste navegador e é usada direto do cliente.

Dados de saúde (LGPD): o texto é enviado à API para ser estruturado. Avalie anonimização/consentimento antes de usar com pacientes reais.
